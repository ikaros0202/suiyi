# ADR-0004：Browser Use 作为真实浏览器验收方式

- 日期：2026-10-13
- 状态：已采纳
- 决定来源：用户本轮明确要求“browser use验收就视为真实浏览器验收成功，以后都是这样”
- 任务：[QA-001（本地归档）](../../archive/README.md)

## 背景

TOOL-001 已安装 Browser Use，并在独立 Edge 访客实例完成页面读取、普通输入框、富文本、结果断言和截图检查。此前仓库将这些操作判为开发工具检查，要求另外证明 TSF 按键路径才能计入真实浏览器验收。用户随后明确改变这项验收规则，要求今后统一采用 Browser Use 的结果。

## 决定

Browser Use 完成对应浏览器场景的操作并核验结果，验收成功即视为真实浏览器验收成功，适用于本轮和后续任务。headless、CDP 或工具的输入实现方式不再成为否定该浏览器验收结论的理由。

按用户的新判定，本轮 TOOL-001 的页面读取、普通输入框、富文本和截图检查计为真实浏览器验收通过。实际动作与证据继续保留，不将 CDP 填写描述成已执行的 TSF 按键，也不补写未运行的用例。

## 理由与影响

采用用户最新明确决定，形成可供后续对话一致执行的浏览器验收方式。AGENTS、验收规范、路线图、工具说明、状态及结果同步此决定；原始 V1 文档保持导入字节，本记录作为后续工程决定覆盖旧浏览器验收限制。

每次结果仍需标明场景、浏览器和工具版本、动作、预期、实际及证据。安装成功不自动通过全部场景；具体未执行或失败的检查如实记录。原生 Windows、Electron、输入故障恢复、敏感上下文和安装恢复继续按各自完成条件执行。此决定不改变产品输入行为，也不改变工具自身的权限与中止规则。
