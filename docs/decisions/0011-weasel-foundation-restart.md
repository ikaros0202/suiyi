# ADR-0011：以小狼毫为基础重启随译

- 日期：2026-10-14。
- 状态：已采纳基础方向；具体版本、构建链和 UI 框架待定；尚未实施。
- 来源：用户明确选择小狼毫，要求完全舍弃现有实现、保留经验、重视 UI、按功能模块由用户选择；细化见 [PD-010](../product/DECISIONS.md)。

## 背景与决定

此前主要自行编写接入、协调和设置，虽使用真实引擎并完成阶段验收，仍缺少对完整开源输入法基础的充分比较。用户确认基于 rime/weasel 重新实现。采用小狼毫的已有工程结构与能力，扩展随译模块；不只更换设置页面，也不把旧代码包装为新基础。

普通输入为默认。三语自动识别、词级短时学习、明确译词上屏分别默认关闭，首个正式版本均包含；本地词频学习默认开启。平台 Windows 11 x64，完整离线安装。现代设置的保存／取消与 UI 质量是前置约束，具体框架须再作技术选择。

固定学习路由：中文词→日语＋假名，日语词→英语词，英语词→中文；整句输入不显示翻译。青简仅作为轻量译词排版与操作参考，其云翻译、持续模式、目标语言选择及生词阈值不随之采纳。

## 替代关系

- ADR-0003、0005、0006、0007、0008、0009 的旧实现绑定不再指导新工程；保留其中仍适用的安全目标、经验和历史结果。
- ADR-0001 的原始档案原则、ADR-0002 的系统输入与职责分离原则仍可沿用，具体方案以本决定为准。
- ADR-0004 的 Browser Use 验收方式继续有效，不回写历史通过项。
- 0010 是旧 M5 的未整合安装决定记录，保留归属与历史；不据此预设新版 MSI 结构。
- 用户旧 M1 保留决定不再要求把 M1 实现作为新产品底座；历史资料与测试结果不改写。

## 上游依据与核查

官方：[rime/weasel](https://github.com/rime/weasel)。本轮只读观察 master 为 4aea1978a351e2ce41af20c8fb88a01ce9802de8，GitHub latest 为 0.17.4（2025-06-04 发布）；这些仅是调研快照，不是已固定依赖。

上游包含 TSF、服务／IPC、UI、部署与安装模块。实现前核对固定提交的 CI、构建文件、子模块、依赖和补丁维护方式；旧 INSTALL 的工具年代不能直接当成当前推荐。Weasel 的 GPL-3.0 许可要求纳入新工程来源与再分发方案，保留上游版权、许可与相应源码，最终包还须逐项核查数据和传递依赖。

## 影响与未决项

旧源码已按 PD-011 保全并移出活动目录；归档由文档对话在用户本轮明确授权下完成。尚未导入新工程或运行构建、安装、卸载、注册。

Weasel 不自动解决三语自动识别、日语转换、三方向释义与现代设置。引擎、数据、扩展点、UI 技术和完整离线包体待评估。用户未要求创建 GitHub fork 或新分支；仍在现有仓库 main 串行开发。

新验证覆盖普通输入、模块独立性、固定三方向、整句禁显、过期结果、译词提交、安全生效与实际 UI／离线交付。旧测试不能折算为新版完成。路线见 [W0～W4](../planning/ROADMAP.md)。
