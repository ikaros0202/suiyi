# 浏览器开发工具与验收边界

用户已采纳 [ADR-0004](../decisions/0004-browser-use-acceptance.md)：Browser Use 完成对应真实浏览器场景操作并核验成功，即计真实浏览器验收成功，不因 headless／CDP 推翻通过项。

## 新版状态

旧项目的 wrapper、版本锁和工具现场已归档。当前活动目录没有 scripts/browser-use.ps1，不提供尚未验证的新版调用命令。历史“已安装”只说明旧现场，不保证移动目录后仍可直接运行。

未来实现任务需要浏览器操作时，先读当前可用的 browser-use 技能，再核实 CLI、浏览器可执行文件、项目独立配置与回环连接；把验证过的版本、启动方式、停止方式和隔离路径写回本文件。公开资料优先用 HTTP／官方文档工具，不为只读资料启动浏览器。

## 继续有效的约束

- 不使用 Edge，除非用户明确改变这项约束；旧历史中的 Edge 证据仍按当时条件成立。
- 不连接个人浏览器配置，不启用云服务或背景录制；多个任务串行共享开发浏览器。
- 操作前核对当前 URL 与控件，登录、验证码和账户授权由用户处理。
- 工具拒绝或中止不能通过更换工具绕过。
- 记录场景、环境、实际动作、预期、结果与证据；未执行写未验证。
- 生成图、静态页面和工具安装成功不能证明产品全部功能通过；原生 UI、Electron、DPI、安装分别验收。

历史源码、固定依赖和记录在 [归档](../../archive/README.md)，只作为复现线索，不作为新工程的默认运行入口。
