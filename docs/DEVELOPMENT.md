# 新版开发准备

当前没有新版源码、构建脚本或可运行安装包。旧开发环境与命令已经归档；不要从历史目录直接运行它们来搭建新版本。

开发从 [V1-001](planning/V1-IMPLEMENTATION-PLAN.md) 开始：固定 Weasel 上游提交，核查其实际 CI／构建链、依赖与许可；在有实现授权的任务中复现，再将验证过的环境和命令记录到这里。当前不把旧 LLVM-MinGW、Mozc、Win32 设置或拟议 UI 框架当成已定方案。

## 目录规则

- 根目录：当前说明与协作规则。
- docs：新版有效规范、任务和验证计划。
- archive：仅本地保存的已提交历史参考，禁止作为默认构建或依赖输入。
- .local-archive：被 Git 忽略的旧工作现场与缓存，不进入公开仓库。
- 新源码与工具目录：待固定上游后按实际组织创建，不预造空骨架。

使用 main 主工作目录，认领写入后按可审阅增量推进。不要使用旧缓存中的绝对路径作为新版运行前提；完整离线交付不能依赖本机旧缓存。

## 本机旧实例

文件归档没有卸载系统中的旧测试 MSI。按最后历史交接，它仍安装但未启用；新版注册／安装前由获授权的实现任务核实，不覆盖个人配置或其他输入法。具体现场留在本地归档，公共说明见 [归档入口](../archive/README.md)。

Browser Use 的对应浏览器验收规则继续有效，见 [使用边界](tools/BROWSER_USE.md)。本轮没有运行产品构建、安装或系统注册。
