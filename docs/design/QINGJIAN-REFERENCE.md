# 青简译词交互参考核对

核对日期：2026-10-14。用户要求参考青简的译词显示与译词上屏；随译工程基础仍为 Weasel。方法：官方文档、固定快照源码与官方渲染快照；没有安装或操作青简 Windows 程序。

## 核实的青简行为

| 内容 | 官方描述或源码证据 |
|---|---|
| 排版 | 候选词在前，旁边是较小的词性和译词，紧凑单行；日语给汉字注假名 |
| 语言 | 青简设置选择一种学习语言；随译不继承这一全局目标，改为用户确定的三方向 |
| 缺失 | 没有翻译时留空，不放占位字符 |
| 写入 | 点候选提交源词，点具体译词提交那条译词；Windows Ctrl＋数字选第一条，Ctrl＋Shift＋数字选第二条 |
| 日语写入 | 只提交译词文本，不把假名标注作为正文一起提交 |
| 无目标 | 没有对应译词时译词动作不提交 |
| 生词颜色 | 官方详细文档按上屏时可见次数计算；少于三轮用橙色，此后转正常色，不等于掌握 |
| 云翻译 | 另有需要云功能的选中文字翻译，与本地候选译词分开 |

## 随译采用方向与边界

用户已要求参考：候选为主、译词为辅，短、近、清楚；不另建大屏释义面板。中文→日语＋假名、日语→英语词、英语→中文是随译自身规则；整句不显示翻译，逐词成句仍逐词提示。

建议普通确认写源词，只有明确点选译词或专用动作才写译词；写入日语不带假名注释。学习开而译词模块关时，注释是只读提示。最终热区和快捷键需对照 Weasel、Windows 与常用宿主冲突后定稿，当前不把 Ctrl＋数字写成已采纳默认。

不自动采用青简的全局学习语言、中英持续模式、九候选、橙色三次阈值、云联想、选区替换或整句翻译。用户已经否定整句学习提示；旧随译的“抽取句内学习点”也随之退出当前范围。
