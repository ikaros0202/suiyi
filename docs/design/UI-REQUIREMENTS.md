# 新版界面与短时学习要求

依据：[PD-010](../product/DECISIONS.md)。小狼毫是工程基础，青简是译词交互参考，详见 [参考核对](QINGJIAN-REFERENCE.md)。本文件尚不是像素定稿。

## 产品层级

普通输入优先，候选词是视觉主体；学习译词靠近对应候选，字号稍小但清楚可读。中文源词只配日语＋假名，日语源词配英语，英语源词配中文。不要并列所有语言、大段释义或学习统计。

学习目的是多次短时重复遇见，不是查词典。新版本不继承旧“固定学习区＋完整详情分页”的硬约束。上屏后短暂显示再自动收起，重新遇到词可再出现；不得宣称显示几次就已经掌握。

## 打字视图

- 词级候选与译词逐一对齐；日语假名与目标词保持明确归属。可用注音或紧凑的次行，实际字号和间距通过真实文本确定。
- 当输入整句时，不显示该句翻译，也不另抽句内词弹提示。由词继续输入成句时，已有词提示应及时撤下；不得残留上一词译文。
- 逐词输入连续成句不触发上述整句禁显；按每次明确词级输入提示。
- 无译词、数据缺失或无法确认词义时省略注释，不用“翻译中”长期占位，不按相同汉字补造读音。
- 原词确认与译词提交的热区、反馈、可用状态分开。译词模块关闭时学习注释仅供看；窗口不抢编辑焦点。
- 候选变化立即撤销旧译词提交资格；隐藏但仍能点到、点错行、迟到结果跳到新词均为阻断问题。
- 边缘避让与多屏 DPI 不能靠把字体缩小完成；保持组合期间位置稳定。实际宽度／候选数量重新设计，不机械继承旧 336 DIP 或四候选要求。
- 自动隐藏只约束上屏后的学习提示，不把正在选词的正常候选窗口按计时器收走。新输入、失焦、敏感位置到来时及时取消旧提示。

## 设置视图

现代 Windows 导航、分类卡片、清楚开关和明暗主题；保存／取消按钮位置稳定，草稿状态清晰。具体框架未定，不能先用旧系统控件拼出页面，再把现代设计推到末期。

## 原生设计验收清单

| 检查 | 必需证据 |
|---|---|
| 信息层级 | 三方向真实词条、多义／缺失／长译词的实际截图 |
| 日语可读性 | 假名与词语对应，放大与缩放后无截断／错位 |
| 密度 | 常用输入内容旁紧凑，不遮正文，不需展开大词典 |
| 状态 | 普通模式、三项开关组合、选词、上屏、收起、无匹配、过期与失焦 |
| 主题／系统缩放 | Windows 11 实际浅深主题与不同 DPI／多屏边缘 |
| 可达性 | 设置键盘导航、可见焦点、读屏名称、对比度；颜色不是唯一状态信号 |
| 保存 | 未保存标识、取消、错误、待安全边界生效、配置冲突 |
| 性能 | 学习查询不阻塞组合；显示／消失无连续闪烁 |

每阶段记录实际截图和操作，不用生成图证明 UI 已实现。时长、上屏后词数、具体像素和键位仍待设计定稿。
