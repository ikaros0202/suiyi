# 随译新版 V1：第一版实现计划

日期：2026-10-14。状态：**计划已建立，产品实现尚未开始。** “新版 V1”是本轮产品范围的工作名称，发行版本号待交付阶段确定；不是归档里的旧 V1 实现。

依据：[PD-010／PD-011](../product/DECISIONS.md)、[模块](../product/MODULES.md)、[界面](../design/UI-REQUIREMENTS.md)、[ADR-0011](../decisions/0011-weasel-foundation-restart.md)。本计划供有相应授权的实现对话逐项认领；文档对话继续管理需求、设计和计划。

## 1. 第一版交付范围

交付一个基于 Weasel 的 Windows 11 x64 输入法和完整离线安装包。默认普通输入，本地词频学习开；提供关闭和清除。现代独立设置支持分类、卡片、开关、明暗主题，以及统一保存／取消。

首版必须同时包含三个默认关闭、可分别开启的附加模块：

| 能力 | 用户得到什么 | 不可偷换的验收目标 |
|---|---|---|
| 三语自动识别 | 在同一输入入口连续输入中文拼音、日文罗马音、英文 | 开启后无需先切持续语言模式；歧义仅纠正本词 |
| 词级学习提示 | 中→日＋假名、日→英、英→中；轻量、短时、反复出现 | 逐词成句仍逐词提示；一次整句不显示，不从句内抽词弹提示 |
| 译词上屏 | 用户明确选择可靠译词后，将其写入当前应用 | 普通确认写源词；过期／缺失目标不得误提交或替换整句 |

不把第一版缩成“只有普通输入，附加功能以后再说”。内部阶段可以先交普通输入，但那只是开发检查点。

本版不纳入整句翻译、划词云翻译、AI 问答、大词典详情页、插件商店、账户同步或其他系统平台。所有已承诺模块的必需运行时和数据随包提供；首次开启不要求下载或账号。

## 3. 最先执行的 V1-001

### 输入

当前规范、官方 Weasel 仓库、旧经验记录。历史代码是参考档案，不作为要继续链接的底座。不得从旧脚本复制一套宿主接入并声称基于 Weasel。

### 工作清单

1. **来源固定**：对比官方稳定版与所需主线能力，选定不可变提交，记录许可、依赖、校验和补丁位置。调研中看见的 latest 不能直接写成已选版本。
2. **上游复现**：在获授权的实现任务中依该提交的实际 CI／构建文件复现普通输入工程，记录编译工具和结果；不要只沿用旧 INSTALL 或旧 LLVM-MinGW 环境。
3. **扩展点核查**：明确 TSF、服务、IPC、候选渲染、配置与安装各承担什么。优先沿用上游，尽量缩小对上游的改动范围。
4. **核心能力可行性**：核对日语输入与英文词级输入如何接入，词语语言和完整范围如何产生；核查离线三方向词库和日语假名来源、覆盖及分发条件。
5. **UI 技术选择**：对照真实 Windows 需求形成候选渲染和独立设置方案，说明与上游集成、资源占用、打包、维护和可达性。C#＋WinUI 或其他框架目前均不是已批准结论。
6. **形成决策**：保存 ADR、依赖／来源清单、最小验证结果与风险；无法满足自动识别或离线词级学习时回到方案决策，不静默删功能。

### 退出门槛

固定来源可复现；不复用旧自建底座；每项关键能力有证据或明确待解决项。若构建失败、日语接入不可用、词库许可不清或 UI 扩展点不可行，则任务未完成，不能用文档齐全代替工程证明。

本轮只写本计划，以上复现／引入动作尚未执行。

## 4. V1-002 必须明确的产品细节

| 待定项 | 不可改变的已确认边界 | 定稿材料 |
|---|---|---|
| 上屏后展示 | 短暂显示再收起，重新遇见可再显示 | 当前词／近期词的紧凑对照，停留时长与新输入到来的状态表 |
| 词句判断 | 词级提示，整句不提示；不能只靠字数或空格 | 中日英普通词、长词、固定短语、多词英语条目、完整句子、混合串的样本表 |
| 多义与假名 | 目标可靠、读音与词义对应 | 多义词、缺失与长译词的可读设计；不扩成词典 |
| 译词动作 | 明确动作才写译词，普通确认写源词 | 原词／译词热区、键位冲突、无目标、学习关闭时入口 |
| 默认普通方案 | 普通输入默认；三模块分别可选 | 首启界面、输入方案及数据选择，不能暗中默认开启三语 |
| 外观 | 现代 Windows、明暗主题、清楚保存／取消 | 实际内容的设置稿，字体、间距、对比、键盘／读屏与 DPI 方案 |

这里的未决项要在影响实现前解决，不让实现者以旧四候选、336 DIP、六方向或旧快捷键自行补齐。
