# 新版路线图

新版第一版的执行入口是 [V1-001～007 实现计划](V1-IMPLEMENTATION-PLAN.md)。本表只保留阶段概览，不另维护第二套任务进度。

| 阶段 | 目的 | 对应任务 |
|---|---|---|
| W0 基线准备 | 归档旧工程、整理需求，固定 Weasel 上游与关键可行性 | DOC-008 已完成归档／规划；V1-001 待开始 |
| W1 UI 与交互 | 紧凑三方向译词、词句边界、短时提示、现代设置与明确译词动作 | V1-002 |
| W2 普通输入基础 | 基于上游建立普通输入、现代设置、托盘、本地词频与偏好保存 | V1-003 |
| W3 可选模块 | 三语自动识别、词级学习、译词上屏与开关组合 | V1-004～006 |
| W4 完整离线交付 | 全包资源、真实宿主／UI／DPI、安装升级与恢复、来源清单 | V1-007 |

归档与计划已完成；新版工程尚未引入。三语无需切换在 V1-004 实现；全部三个附加功能属于首个正式可用版本，均默认关闭。

UI 从 W1 开始，在 W2～W4 用实际窗口持续核验。各任务须有当前对话授权与独立证据；旧 M 阶段不继续接续，历史入口见 [archive](../../archive/README.md)。
