# 旧实现经验：保留认识，不延用自建底座

状态：2026-10-14 重启后的经验记录。依据 [PD-010](../product/DECISIONS.md)。旧已提交源码与记录已归档；M5 未提交现场及旧缓存仅保存在本地归档。路径与恢复边界见 [归档说明](../../archive/README.md)。

| 经验 | 对新版的要求 | 历史出处 |
|---|---|---|
| 曾把三引擎可用理解成三语无需切换 | 单独验证连续中文拼音、日文罗马音、英文和歧义；开关默认关不改变开启后的目标 | PD-002、M2-A |
| 设置能工作却像旧式系统工具 | UI 先设计；实际原生窗口检查，不用浏览器设置页代替原生视觉 | M4 契约与用户重启反馈 |
| 固定学习区、详情与历史越做越多 | 收敛到词级、短时重复；整句禁显，不做词典 | 新 PD-010 替代旧 M3 目标 |
| 只用同形汉字连词义会出错 | 日语语言、义项与受限读音分别核实；跨语数据不能只按字形 join | M2-B 数据说明 |
| 输入候选改变后旧结果可能迟到 | 绑定输入／候选／会话／配置版本，结果立刻失效；先保证不可误提交 | ADR-0005～0008 |
| 提交请求不等于真的写入 | 宿主明确成功后才更新提交相关状态；失败不自动换确认方式 | M2-A／M2-B 提交契约 |
| 学习词库加载、索引等进入宿主会放大资源代价 | 先理解 Weasel 服务边界，避免每个目标应用重复承担重查询 | 开源基础初审 |
| 浏览器通过有明确范围 | 保留 Browser Use 对应通过事实；原生 UI、Electron、DPI、安装分别取证 | ADR-0004、M4／M5 |
| TSF 输入范围与宿主差异会漏掉敏感场景 | 在实际目标应用检查输入范围获取失败／替代接口，按缺失保守处理，不假设 fixture 覆盖全部 | M5 任务的原生 scope 修正 |
| Alt 类按键受系统菜单与 TSF 路径影响 | 新译词快捷键先审查实际宿主冲突；不直接继承旧默认 | M5 任务与青简按键文档 |
| 完整离线交付不只是一个 MSI 文件 | 清点运行时、词库、许可、数据版本、升级与失败恢复；离线开启所有模块实测 | 未完成的 M5 安装任务 |

## 历史事实如何保留

旧 M2-B 28 组、M3 60 组、M4 73 组 Browser Use 成功保持各自条件下的事实；M5 的 101 组安装后浏览器回归及未完成的 Electron／维护项按原任务保留。它们不证明新 Weasel 版本通过了任何场景。

两份用户原稿、原型源码和截图保持原始摘要。旧 M1 冻结指历史不改写，不再要求旧实现成为新产品的不可替换基础。未提交成果已完整保存在被忽略的本地归档，不进入公共提交；原始字节不格式化。

保留测试思想、错误条件、数据许可经验、用户反馈；具体测试代码、构建脚本、内部类和二进制不自动复制到新工程。实际复用任何依赖或资料都要重新核对范围、许可和版本。
