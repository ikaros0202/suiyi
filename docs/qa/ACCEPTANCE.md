# 新版验收计划

## 当前验收计划：Weasel 新版（2026-10-14）

依据 [PD-010](../product/DECISIONS.md)、[模块](../product/MODULES.md) 与 [UI 要求](../design/UI-REQUIREMENTS.md)。以下 W 用例是新版本待执行计划，均未运行；旧测试通过不折算为新版本结果。

| 编号 | 场景与预期 | 主要阶段 |
|---|---|---|
| W-01 | 离线干净安装，普通输入可用，三附加模块均关，本地词频学习开；不开网络也能逐项开启全部首版功能 | W2／W4 |
| W-02 | 正常中文／英文及选定方案的组合编辑、源词提交、原样、取消、标点与导航不被学习干扰 | W2 |
| W-03 | 开启自动识别后，同框连续输入中、日、英，无需预切；歧义纠正仅限本词且保留组合 | W3 |
| W-04 | 真实中文词显示正确日语与对应假名；日语词显示英语词；英语词显示中文；无任意全局学习对误覆盖 | W3 |
| W-05 | 逐词组成一句话，每个词按对应方向提示；一次输入整句无翻译，仍能正常输入；不抽句内学习词 | W3 |
| W-06 | 当前词继续扩展成句、换候选、换应用或失焦时旧译词及时消失且不可提交；迟到结果不重现 | W3 |
| W-07 | 无词条、多义不确定、同形中日词、缺假名、长词及资源缺失不臆造；不依赖固定字数或空格判断句子 | W3 |
| W-08 | 学习上屏后短暂显示再收起，重新遇见仍出现；选词窗口不因该计时器消失，不抢焦点 | W3 |
| W-09 | 普通确认只写源词；明确译词动作才写所选完整目标，日语不混入假名；缺目标／过期／提交失败不换成普通确认 | W3 |
| W-10 | 三开关的全部八种组合；学习与译词不强依赖自动识别；学习开、译词关时点击注释不会写译文 | W3 |
| W-11 | 模块关闭不再执行它的展示、记录与键位；共享查询不得恢复已关闭功能；本地词频开关与学习提示独立 | W3 |
| W-12 | 设置草稿、保存、取消、未保存退出、冲突与失败；组合中保存影响行为的选项不隐式提交或丢串 | W2／W3 |
| W-13 | 密码／明确敏感范围无查询无记录；输入范围读取失败保守处理；无应用全文／逐键日志进入诊断 | W2／W3 |
| W-14 | 实际原生 UI 的浅深主题、长译词／假名、焦点、键盘与读屏；系统缩放、多屏边缘无遮挡／截断 | W1～W4 |
| W-15 | 真实安装、升级、修复、失败恢复、卸载与用户设置保留；运行时、数据、许可、摘要完整 | W4 |
| W-16 | 浏览器普通／富文本、原生编辑器、Electron分别验证输入与焦点；记录宿主版本、操作和证据 | W2～W4 |

词句边界、多义呈现、停留时长与键位应先在 W1 定稿，再给对应场景确定预期，不能测试时悄悄扩范围。整句无提示是功能要求，不以删除整句输入支持实现。

按 [ADR-0004](../decisions/0004-browser-use-acceptance.md)，Browser Use 对应操作并核验成功仍计真实浏览器验收成功。原生 UI、系统 DPI 和安装须各自证据；生成图与静态原型不作为产品通过证据。结果使用 [模板](RESULT_TEMPLATE.md)，新结果另建，不覆盖旧记录。


第一版执行分工见 [V1 实现计划](../planning/V1-IMPLEMENTATION-PLAN.md)。旧验收计划和结果已归档，不与当前未执行场景混排。
