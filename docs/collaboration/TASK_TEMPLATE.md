# TASK-ID：任务名称

复制到 `docs/collaboration/tasks/` 后填写；这是模板，不是进行中的任务。

| 字段 | 内容 |
|---|---|
| 状态／更新时间 | 待开始／YYYY-MM-DD |
| 用户请求与授权范围 | 用自己的话准确记录，必要时引用一句决定 |
| 负责人／对话 | 可接续的标识 |
| 分支／工作目录 | main／项目主工作目录；不提交个人账户路径 |
| 允许修改 | 明确文件或模块 |
| 只读依赖 | 相关任务、文档或接口 |
| 文件占用 | 未认领／已认领／已释放；认领前确认上一写入者已释放，同一时间只有一个写入者 |

## 目标与完成条件

具体说明要解决的问题、交付物及如何证明完成。列出本任务不包含的相邻阶段，只写有必要的边界。

## 决定与实施结果

记录最终改动及理由，链接适用 V1 条款或 ADR。提案和事实分开。
