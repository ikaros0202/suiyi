# 设置页面规范

当前依据：[PD-010](DECISIONS.md)、[模块边界](MODULES.md)。替代旧 M4 的产品默认值和界面约束；旧实现结果不回写。

## 已确认体验

托盘入口和独立设置窗口；现代 Windows 风格，清楚的分类、卡片、开关、明暗主题。所有设置先进入未保存草稿，统一点击“保存”后生效；“取消”放弃本次未保存修改。退出有未保存修改时给出保存／放弃／继续编辑的清楚选择。

功能开关不能堆进打字浮窗。每个选项说明作用、默认值、何时生效和必要依赖。升级保留用户选择，不因新增模块擅自开启它。

## 信息架构草案

以下分类为设计提案，可在视觉评审中调整；已确认的功能和默认值不随分类改变。

| 分类 | 内容 |
|---|---|
| 功能 | 三语自动识别、学习提示、译词上屏三个独立开关，默认全关 |
| 输入 | 普通输入方案、候选与标点；本地词频学习默认开，提供关闭和清除入口 |
| 学习与译词 | 固定方向说明：中→日＋假名、日→英、英→中；整句不提示；短时提示时长等待定项不伪装成现成设置 |
| 外观 | 浅色／深色，字号、假名可读性、紧凑度；跟随系统主题可作为设计提案 |
| 快捷键 | 普通与译词操作、冲突检查和恢复默认；具体键位待定 |
| 数据与隐私 | 离线资源版本／状态，用户词库与学习记录分别清除；无输入内容诊断 |
| 关于 | 软件／上游版本、第三方声明、项目链接与升级信息 |

清除已经保存的数据是独立操作，不伪装成可取消草稿：点击后先说明对象与不可撤销范围，由用户明确确认；不能因点击设置“取消”而让人误以为清除也已撤回。关闭本地词频学习不自动删除既有词库。

## 保存契约

- 保存前校验全部相关项；失败时保留草稿并定位错误，不发生半套选项生效。
- 保存成功给出反馈；需要等本次输入结束、部署词库或重启组件的例外明确提示。
- 当前组合、候选和待提交译词不能因设置切换被误提交。依赖变更应取消旧查询资格。
- 多窗口、旧版本配置、损坏配置、升级迁移的冲突与恢复要可解释；不悄悄覆盖较新的用户选择。
- 禁用开关对应的功能真正停止，不能只在设置界面改颜色。

## 离线与后续扩展

完整离线安装是首版要求；开功能不要求注册账户、填 API Key 或临时下载组件。当前没有批准联网翻译或云问答进入新首版；旧 M4 的受限联网服务不是必须迁移的功能。

新想法先说明用户目标、默认行为、数据影响和独立关闭方式，再决定放在哪个分类。不要为技术内部状态暴露大量用户无从判断的开关。

## UI 验收

以实际 Windows 11 设置程序验证键盘导航、焦点、读屏名称、明暗主题、缩放、长中文文案、未保存状态及失败反馈。浏览器功能测试有其对应证据，但不能代替原生设置页面的视觉评审。验收详见 [UI 要求](../design/UI-REQUIREMENTS.md)。
