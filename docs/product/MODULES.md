# 可选功能与模块边界

依据：[PD-010](DECISIONS.md)。面向新的 Weasel 实现；本文件描述产品契约，尚未实现。

## 模块与默认值

| 模块 | 安装后状态 | 用途 | 关闭后的行为 |
|---|---|---|---|
| 基础输入 | 必需 | 普通候选、组合编辑、源词确认、取消、标点和宿主接入 | 不能用附加模块取代 |
| 本地词频学习 | 开 | 本机候选排序和用户词库习惯 | 不新增个性化学习；保留／清除旧数据由用户明确选择 |
| 三语自动识别 | 关 | 中文拼音、日文罗马音、英文连续输入，无需预切持续模式 | 按用户选择的普通输入方案工作 |
| 学习提示 | 关 | 当前词按固定三方向显示短译词，短时重复接触 | 无学习提示，不生成此模块的接触记录 |
| 译词上屏 | 关 | 明确选择译词后写入当前应用 | 不接管译词动作；普通源词输入正常 |
| 设置与数据管理 | 必需 | 保存／取消、外观、键位、数据清除与模块选项 | 始终能进入设置 |

模块是内部职责与用户功能选择，不代表首版承诺动态插件平台或插件商店。所有首版模块和必需资源在完整离线安装包内，不靠首次开启联网下载。

## 三方向学习路由

源词语言决定目标：中文→日语＋假名，日语→英语词，英语→中文。不提供旧六方向任意选择作为首版前提。启用自动识别时使用当前词已确定的源语言；关闭时使用当前输入方案与词条的可靠语言信息。不能按汉字外形认定是中文或日文。

“逐词组成一句话”仍对每个词提示。“一次组合／提交整句”不显示翻译，不做句内学习点提取，也不补一个历史词提示冒充当前结果。普通整句输入不受此限制。

可靠完整词条匹配是设计方向，不以固定字符数划线。英文多词词条、固定短语、同形中日词的边界需通过样本确定；不确定时保留普通输入并不显示学习译词。

## 组合与依赖

- 自动识别、学习、译词上屏可分别开启；学习和译词不以开启自动识别为前置条件。
- 学习开、译词上屏关：译词只读，普通确认仍写原词；点击注释不能偷偷写译文。
- 学习关、译词上屏开：通过明确译词入口临时展示可选择的可靠目标，不自动展示学习提示或维护学习历史。入口细节在 UI 阶段定稿。
- 两者均开：共享同一可靠词义结果，但是否展示、是否允许提交分别校验。
- 附加模块关闭后不为它查询、计时、接管按键或联网。被别的已启用模块需要的共享查询可继续，但不能恢复关闭模块的行为。
- 设置保存时若正在组合，影响候选／提交的切换应延到安全边界，并明确提示；不能中途清空或隐式提交。

## 共同可靠性要求

查询与提交资格绑定源词完整范围、候选、词义、语言、会话和版本。候选／应用／焦点改变即失效。没有词条或可靠假名就不伪造；超时不阻塞普通打字。只有真正成功写入的结果可记为一次提交。

译词上屏仅由明确动作触发，不把局部译词替换整句。当前需求不含整句翻译、划词云翻译或通用问答。最终键位不直接继承旧 Alt＋Enter／Ctrl＋Enter，也不因青简采用 Ctrl＋数字便无条件照搬。

本地词频学习与外语短时记忆分开管理。出现次数不等于用户已经记住；不因达到固定次数永久隐藏词语。敏感位置不查询、不记录，不保存逐键日志或其他应用全文。
