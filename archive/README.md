# 历史归档

本目录的 legacy 快照仅保存在本地、不上传重建后的 GitHub；本说明与归档规则纳入新仓库。本目录是历史参考，**不属于新版源码、当前规范或默认构建输入**。新版从 [V1 实现计划](../docs/planning/V1-IMPLEMENTATION-PLAN.md) 开始。

## 两层保存

| 层 | 内容 | 保存位置 |
|---|---|---|
| 本地已提交历史快照 | a18f04d 已提交的 276 个文件：旧实现、脚本、测试、文档、QA、原稿和设计；包括当时已提交的重启文档 | 项目根目录的 archive/legacy-2026-10-14 |
| 本机完整现场 | 归档开始时的 365 个已跟踪／未跟踪文件，含 M5 的 9 个修改与 89 个未跟踪文件；旧依赖、构建、工具缓存及本机状态一并搬移 | 项目根目录的 .local-archive/2026-10-14-pre-weasel，Git 忽略 |

两者用途不同：已提交历史快照不包含未整合 M5 的新增实现／证据；本地现场完整保存其原始字节和归属。M5 仍未完成，归档不表示交付通过，也不把未提交现场上传到公共仓库。

两层本地归档都不依赖新 GitHub 仓库可获取；原 Git 历史另保存于本地归档的 git-history.git，全部引用另有 legacy-all.bundle。需要跨机器转移它时另行选择与审查；本次将新文档起点推送到同名重建仓库；这些历史归档不随之上传。

## 使用方式

- 看经验，优先读 [当前经验总结](../docs/planning/LEGACY-LESSONS.md)。
- 查当时的文件，使用快照 tree；路径映射和 SHA-256 在 MANIFEST。
- 历史文档里的“当前”“继续 M5”、命令、角色和授权均属于当时语境，不能覆盖当前 AGENTS。
- 旧 AGENTS 与 Git 属性／忽略／编辑器控制文件已改名为 .snapshot.txt，保持内容但不作为生效规则；指向其原名的历史链接通过 MANIFEST 查找。
- 不直接运行档案内构建、安装或注册脚本；本地运行路径已改变，档案不承诺直接可执行。
- 不修改冻结档案正文；纠正与新结论写在当前 docs，并引用历史来源。

## 恢复原则

需要恢复时先确认目的、写入占用和实施授权；按清单取回特定文件或在另行明确授权的隔离位置恢复。不得把旧根目录整包覆盖到当前项目，不重置 main，也不据归档脚本改变系统输入法。

文件归档没有卸载旧测试 MSI。开始新版系统级验证前需核实旧安装、注册和个人设置；本轮只保全文件。

## 本地历史检索

使用文件管理器进入 archive/legacy-2026-10-14/tree，可按旧目录查找源码、原稿、任务和 QA；其上一级 MANIFEST.json 给出所有原路径与摘要。新 GitHub 只提供当前规范和这份检索说明，不提供这些历史文件下载。
